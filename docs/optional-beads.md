# Optional: an issue tracker

The quickstart uses files (`examples/project.md` and the register). Add a tracker when the list of open items no longer fits in those files.

Any tracker is fine. One that agents can drive from the shell keeps handoffs short: create an item, claim it, note the step, close it when the result is checked.

Suggested loop:

1. List what is ready.
2. Claim one item.
3. Do the work.
4. Close it with the result.
5. Sync.

Keep one owner on each item. Do not close an item the human asked to keep open until they say so.

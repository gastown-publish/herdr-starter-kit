# Optional: a chat relay

A relay lets the human answer from a phone. You do not need one on a single Mac with Claude Code.

If you add one:

- The master asks in the pane and in the chat with the same number. The first answer wins. Relay it word for word.
- A shared group has no secrets, account ids, host names, or other people's private matters. A private question stays in the master pane.
- Pin a short status per project. Keep a to-do list of open items only. Remove an item after the reply is handled.
- Recurring work runs on the machine that is on, not on a laptop that sleeps. An example schedule is `examples/jobs.json`.

This kit does not ship a bot, a token, or a dashboard. Write or choose a relay that reads a local config file you never commit.
